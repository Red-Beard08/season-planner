# Season Planner

Season Planner is a mobile-compatible, Markdown-first planning tool for conceptual life load. It organizes overlapping seasons, years, quarters, months, weeks, people, places, durations, and recurring patterns without becoming a calendar or scheduling service.

Records live under `Collections/Season Planner/` by default. Recurring patterns are calculated virtually; only explicit exceptions and notes become Markdown records. Family Companion, Journal Companion, and Study Planner data are read through optional adapters and are never rewritten automatically.

The plugin exposes a Red-Beard Dashboard launcher and widget when that add-on is present, while remaining fully functional on its own.
